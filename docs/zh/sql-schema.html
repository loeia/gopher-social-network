概述

Gopher Social Network 使用 PostgreSQL 16 作为主数据库，Redis 作为缓存层。

数据库信息

数据库类型 PostgreSQL 16.3
默认数据库名 gopher-social-network
默认用户 admin
连接池配置 最大连接 30，空闲连接 30，空闲超时 15m

表清单

post_likes 帖子点赞表 关联表

ER 关系图

实体关系图展示了各表之间的关联关系。

关系说明

  • 多对一 users.role_id → roles.id: 每个用户有一个角色
  • 一对多 posts.user_id → users.id: 每个用户可以发布多个帖子
  • 一对多 comments.post_id → posts.id: 每个帖子可以有多个评论
  • 一对多 comments.user_id → users.id: 每个用户可以发表多个评论
  • 自关联 comments.parent_id → comments.id: 评论支持多级回复
  • 一对多 comments.reply_to_user_id → users.id: 回复目标用户
  • 多对多 followers: 用户之间的关注关系（自关联）
  • 多对多 post_likes: 用户点赞帖子的关系
  • 多对多 comment_likes: 用户点赞评论的关系

表结构详解

roles 主表

角色表，定义系统中的用户角色和权限层级。

列名 类型 约束 说明
id SERIAL PRIMARY KEY 角色 ID
name VARCHAR(255) UNIQUE NOT NULL 角色名称 (user/moderator/admin)
description VARCHAR(255) 角色描述
level INTEGER NOT NULL 权限层级 (1=user, 2=moderator, 3=admin)

预设数据

INSERT INTO roles (name, description, level) VALUES
    ('user', '普通用户', 1),
    ('moderator', '版主', 2),
    ('admin', '管理员', 3);
users 主表

用户表，存储所有用户信息。

列名 类型 约束 说明
id BIGSERIAL PRIMARY KEY 用户 ID
username VARCHAR(255) UNIQUE NOT NULL 用户名
email VARCHAR(255) UNIQUE NOT NULL 邮箱地址
password VARCHAR(255) NOT NULL 密码哈希 (bcrypt)
created_at TIMESTAMPTZ DEFAULT NOW() 创建时间
is_active BOOLEAN DEFAULT FALSE 是否已激活
role_id INTEGER FOREIGN KEY → roles.id 角色 ID
token_ver INTEGER DEFAULT 0 Token 版本号（用于失效旧 Token）
avatar BYTEA 头像图片数据
avatar_mime VARCHAR(50) 头像 MIME 类型
bio TEXT 个人简介
links VARCHAR(255)[] DEFAULT '{}' 个人链接数组
show_email BOOLEAN DEFAULT FALSE 是否公开邮箱
is_banned BOOLEAN DEFAULT FALSE 是否被封禁
followers_count BIGINT DEFAULT 0 粉丝数（冗余字段）
following_count BIGINT DEFAULT 0 关注数（冗余字段）
posts_count BIGINT DEFAULT 0 帖子数（冗余字段）
likes_count BIGINT DEFAULT 0 获赞数（冗余字段）
replies_count BIGINT DEFAULT 0 回复数（冗余字段）
设计说明：使用冗余字段（followers_count 等）存储计数，避免频繁的 COUNT 查询，通过触发器自动维护计数一致性。
posts 主表

帖子表，存储用户发布的帖子内容。

列名 类型 约束 说明
id BIGSERIAL PRIMARY KEY 帖子 ID
user_id BIGINT FOREIGN KEY → users.id NOT NULL 作者 ID
title VARCHAR(255) NOT NULL 帖子标题
content TEXT NOT NULL 帖子内容（支持 Markdown）
tags VARCHAR(255)[] DEFAULT '{}' 标签数组
version INTEGER DEFAULT 1 乐观锁版本号
created_at TIMESTAMPTZ DEFAULT NOW() 创建时间
updated_at TIMESTAMPTZ DEFAULT NOW() 更新时间
comment_count BIGINT DEFAULT 0 评论数（冗余字段）
like_count BIGINT DEFAULT 0 点赞数（冗余字段）
view_count BIGINT DEFAULT 0 浏览量

乐观锁更新示例

-- 更新帖子时检查版本号
UPDATE posts 
SET title = $1, content = $2, tags = $3, 
    updated_at = NOW(), version = version + 1 
WHERE id = $4 AND version = $5 
RETURNING version, updated_at;
comments 主表

评论表，支持多级回复的评论系统。

列名 类型 约束 说明
id BIGSERIAL PRIMARY KEY 评论 ID
post_id BIGINT FOREIGN KEY → posts.id NOT NULL 所属帖子 ID
user_id BIGINT FOREIGN KEY → users.id NOT NULL 评论者 ID
content TEXT NOT NULL 评论内容
parent_id BIGINT FOREIGN KEY → comments.id 父评论 ID（NULL 表示一级评论）
reply_to_user_id BIGINT FOREIGN KEY → users.id 回复目标用户 ID
created_at TIMESTAMPTZ DEFAULT NOW() 创建时间
like_count BIGINT DEFAULT 0 点赞数（冗余字段）
多级回复设计：通过 parent_id 自关联实现评论树结构。一级评论的 parent_id 为 NULL，回复的 parent_id 指向父评论。最多支持两级回复。
followers 关联表

关注关系表，存储用户之间的关注关系。

列名 类型 约束 说明
user_id BIGINT FOREIGN KEY → users.id NOT NULL 被关注者 ID
follower_id BIGINT FOREIGN KEY → users.id NOT NULL 关注者 ID
created_at TIMESTAMPTZ DEFAULT NOW() 关注时间

约束

-- 联合唯一约束，防止重复关注
UNIQUE (user_id, follower_id)

-- 检查约束，防止自关注
CHECK (user_id != follower_id)
post_likes 关联表

帖子点赞表。

列名 类型 约束 说明
post_id BIGINT FOREIGN KEY → posts.id NOT NULL 帖子 ID
user_id BIGINT FOREIGN KEY → users.id NOT NULL 点赞用户 ID
created_at TIMESTAMPTZ DEFAULT NOW() 点赞时间

约束

-- 联合唯一约束，防止重复点赞
UNIQUE (post_id, user_id)
comment_likes 关联表

评论点赞表。

列名 类型 约束 说明
comment_id BIGINT FOREIGN KEY → comments.id NOT NULL 评论 ID
user_id BIGINT FOREIGN KEY → users.id NOT NULL 点赞用户 ID
created_at TIMESTAMPTZ DEFAULT NOW() 点赞时间

约束

-- 联合唯一约束
UNIQUE (comment_id, user_id)
user_invitations 临时表

用户激活邀请表，存储未激活用户的邀请令牌。

列名 类型 约束 说明
user_id BIGINT FOREIGN KEY → users.id NOT NULL 用户 ID
token VARCHAR(255) NOT NULL 激活令牌（SHA256 哈希）
expiry TIMESTAMPTZ NOT NULL 过期时间
清理策略：用户激活后，对应的邀请记录会被删除。
password_resets 临时表

密码重置表，存储密码重置令牌。

列名 类型 约束 说明
token VARCHAR(255) NOT NULL 重置令牌（SHA256 哈希）
user_id BIGINT FOREIGN KEY → users.id NOT NULL 用户 ID
expiry TIMESTAMPTZ NOT NULL 过期时间（默认 15 分钟）
安全策略：密码重置后，对应记录会被删除。同时 user 的 token_ver 会递增，使旧 Token 失效。

触发器与约束

数据库级别的约束和触发器，用于维护数据一致性。

触发器：自动更新帖子点赞计数

-- 当 post_likes 表插入或删除时，自动更新 posts.like_count
CREATE OR REPLACE FUNCTION update_post_like_count()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'INSERT' THEN
        UPDATE posts SET like_count = like_count + 1 WHERE id = NEW.post_id;
    ELSIF TG_OP = 'DELETE' THEN
        UPDATE posts SET like_count = like_count - 1 WHERE id = OLD.post_id;
    END IF;
    RETURN NULL;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trigger_update_post_like_count
    AFTER INSERT OR DELETE ON post_likes
    FOR EACH ROW
    EXECUTE FUNCTION update_post_like_count();

触发器：自动更新关注计数

-- 当 followers 表插入或删除时，自动更新 users 的 followers_count 和 following_count
CREATE OR REPLACE FUNCTION update_user_follow_counts()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'INSERT' THEN
        -- 被关注者的粉丝数 +1
        UPDATE users SET followers_count = followers_count + 1 WHERE id = NEW.user_id;
        -- 关注者的关注数 +1
        UPDATE users SET following_count = following_count + 1 WHERE id = NEW.follower_id;
    ELSIF TG_OP = 'DELETE' THEN
        -- 被关注者的粉丝数 -1
        UPDATE users SET followers_count = followers_count - 1 WHERE id = OLD.user_id;
        -- 关注者的关注数 -1
        UPDATE users SET following_count = following_count - 1 WHERE id = OLD.follower_id;
    END IF;
    RETURN NULL;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trigger_update_user_follow_counts
    AFTER INSERT OR DELETE ON followers
    FOR EACH ROW
    EXECUTE FUNCTION update_user_follow_counts();

触发器：自动更新 updated_at 时间戳

-- 当 posts 表更新时，自动设置 updated_at 为当前时间
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trigger_update_posts_updated_at
    BEFORE UPDATE ON posts
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();

索引设计

为提高查询性能而设计的索引。

users 表索引

idx_users_email (email) idx_users_username (username) idx_users_role_id (role_id) idx_users_is_active (is_active)

posts 表索引

idx_posts_user_id (user_id) idx_posts_created_at (created_at DESC) idx_posts_tags (tags USING GIN) idx_posts_title_trgm (title gin_trgm_ops)

comments 表索引

idx_comments_post_id (post_id) idx_comments_user_id (user_id) idx_comments_parent_id (parent_id) idx_comments_created_at (created_at)

followers 表索引

idx_followers_user_id (user_id) idx_followers_follower_id (follower_id)

post_likes 表索引

idx_post_likes_post_id (post_id) idx_post_likes_user_id (user_id)

comment_likes 表索引

idx_comment_likes_comment_id (comment_id) idx_comment_likes_user_id (user_id)
GIN 索引：posts 表的 tags 字段使用 GIN (Generalized Inverted Index) 索引，支持高效的数组包含查询（@> 操作符）。
pg_trgm 扩展：posts 表的 title 字段使用 pg_trgm 扩展的 GIN 索引，支持高效的模糊搜索（ILIKE 查询）。

依赖关系

表之间的外键依赖关系。

源表 源列 目标表 目标列 级联操作
users role_id → roles id RESTRICT
posts user_id → users id CASCADE
comments post_id → posts id CASCADE
comments user_id → users id CASCADE
comments parent_id → comments id CASCADE
comments reply_to_user_id → users id SET NULL
followers user_id → users id CASCADE
followers follower_id → users id CASCADE
post_likes post_id → posts id CASCADE
post_likes user_id → users id CASCADE
comment_likes comment_id → comments id CASCADE
comment_likes user_id → users id CASCADE
user_invitations user_id → users id CASCADE
password_resets user_id → users id CASCADE

级联操作说明

操作 说明
CASCADE 删除父记录时，自动删除所有关联的子记录
RESTRICT 如果存在关联记录，则禁止删除父记录
SET NULL 删除父记录时，将子记录的外键设为 NULL

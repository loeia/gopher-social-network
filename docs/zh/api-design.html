概述

Gopher Social Network 后端采用 RESTful API 设计风格，使用 Go 语言和 Chi Router 框架构建。

基础信息

基础 URL http://localhost:8080
数据格式 JSON (Content-Type: application/json)
认证方式 JWT Bearer Token
请求超时 60 秒
速率限制 每 IP 5 秒内最多 20 次请求（可配置）

认证请求格式

Authorization: Bearer <jwt_token>

分页参数

参数 类型 默认值 说明
limit int 20 每页数量 (1-20)
offset int 0 偏移量
sort string desc 排序方式 (asc/desc)

认证 API

处理用户注册、登录、账号激活和密码重置。

POST /auth/register 公开

注册新用户账号，系统将发送激活邮件。

请求体

字段 类型 必需 说明
username string 是 用户名，唯一
email string 是 邮箱地址，唯一
password string 是 密码

请求示例

{
    "username": "newuser",
    "email": "user@example.com",
    "password": "securepassword123"
}

响应

// 201 Created
{
    "message": "registration successful, please check your email to activate your account"
}
POST /auth/token 公开

用户登录，验证凭据并返回 JWT 令牌。

请求体

字段 类型 必需 说明
email string 是 注册邮箱
password string 是 密码

响应

// 201 Created
{
    "token": "eyJhbGciOiJIUzI1NiIs..."
}
JWT Token 包含的 Claims：
  • sub: 用户 ID
  • exp: 过期时间（默认 72 小时）
  • iat: 签发时间
  • iss: 签发者
  • ver: Token 版本号（用于失效旧 Token）
POST /auth/activate/{token} 公开

通过邮件中的激活链接激活用户账号。

路径参数

参数 类型 说明
token string 激活令牌（SHA256 哈希存储）

响应

// 200 OK
{
    "message": "account activated successfully"
}
POST /auth/forgot-password 公开

发送密码重置邮件。

请求体

字段 类型 必需 说明
email string 是 注册邮箱

响应

// 200 OK
{
    "message": "password reset email sent"
}
POST /auth/reset-password 公开

通过令牌重置密码。

请求体

字段 类型 必需 说明
token string 是 密码重置令牌
password string 是 新密码

响应

// 200 OK
{
    "message": "password reset successfully"
}

帖子 API

处理帖子的创建、查询、更新、删除和点赞。

GET /posts/free 公开

获取随机帖子列表（用于首页推荐）。

查询参数

参数 类型 默认值 说明
limit int 20 返回数量

响应

// 200 OK
[
    {
        "id": 1,
        "user_id": 1,
        "title": "Go 并发编程",
        "content": "...",
        "tags": ["golang", "并发"],
        "version": 1,
        "created_at": "2026-01-01T00:00:00Z",
        "updated_at": "2026-01-01T00:00:00Z",
        "comment_count": 5,
        "like_count": 10,
        "view_count": 100,
        "user": {
            "username": "alice"
        }
    }
]
GET /posts/search 公开

搜索帖子，支持关键词、标签、作者和时间范围过滤。

查询参数

参数 类型 必需 说明
search string 否 标题搜索关键词
tags string 否 标签过滤（逗号分隔）
author string 否 作者用户名
since string 否 起始时间 (RFC 3339)
until string 否 结束时间 (RFC 3339)
limit int 否 每页数量 (1-20)
offset int 否 偏移量
sort string 否 排序 (asc/desc)

请求示例

GET /posts/search?search=Go&tags=golang,并发&limit=10
GET /posts/{postId} 公开

获取帖子详情，同时增加浏览量。

路径参数

参数 类型 说明

响应

// 200 OK
{
    "id": 1,
    "user_id": 1,
    "title": "Go 并发编程",
    "content": "...",
    "tags": ["golang"],
    "version": 1,
    "created_at": "2026-01-01T00:00:00Z",
    "updated_at": "2026-01-01T00:00:00Z",
    "comment_count": 5,
    "like_count": 10,
    "view_count": 101,
    "user": {
        "username": "alice"
    }
}
POST /posts 需认证

创建新帖子。

请求体

字段 类型 必需 说明
title string 是 帖子标题
content string 是 帖子内容
tags string[] 否 标签数组

响应

// 201 Created
{
    "id": 1,
    "title": "新帖子",
    "content": "...",
    "tags": ["golang"],
    "created_at": "2026-01-01T00:00:00Z",
    "updated_at": "2026-01-01T00:00:00Z"
}
PATCH /posts/{postId} 需认证

更新帖子（仅作者或版主可操作）。使用乐观锁（version 字段）防止并发冲突。

请求体

字段 类型 必需 说明
title string 否 新标题
content string 否 新内容
tags string[] 否 新标签
version int 是 当前版本号
乐观锁机制：更新时必须提供当前 version，数据库会检查 version 是否匹配。若不匹配返回 404，表示帖子已被其他人修改。
DELETE /posts/{postId} 需认证

删除帖子（仅作者或管理员可操作）。

PUT /posts/{postId}/like 需认证

点赞帖子（幂等操作，重复点赞无影响）。

DELETE /posts/{postId}/like 需认证

取消点赞帖子。

管理员 API

管理员专用接口，需要 admin 角色权限。

PATCH /admin/users/{username}/ban 管理员

封禁用户，被封禁用户将无法登录。

路径参数

参数 类型 说明
username string 要封禁的用户名

响应

// 204 No Content
副作用：系统将发送封禁通知邮件给被封禁用户。
PATCH /admin/users/{username}/unban 管理员

解封用户。

响应

// 204 No Content
副作用：系统将发送解封通知邮件给被解封用户。

中间件

请求处理流程中的中间件链。

请求处理流程

CORS → Recoverer → RequestID → ClientIP → Logger → Timeout → RateLimiter → Handler

中间件说明

中间件 说明
CORS 处理跨域请求，允许前端访问 API
Recoverer 捕获 panic 并返回 500 错误，防止服务崩溃
RequestID 为每个请求生成唯一 ID，便于追踪
ClientIP 提取客户端 IP 地址
Logger 记录请求日志（方法、路径、状态码、耗时）
Timeout 设置请求超时（60 秒）
RateLimiter 基于 IP 的速率限制（可选，依赖 Redis）
AuthTokenMiddleware 验证 JWT Token 并注入用户信息到上下文
postsContextMiddleware 加载帖子到上下文
commentsContextMiddleware 加载评论到上下文
checkPostOwnerShip 验证用户是否为帖子所有者或具有所需角色
checkCommentOwnerShip 验证用户是否为评论所有者或具有所需角色
verifyAdminPermMiddleware 验证用户是否具有管理员权限

角色权限层级

角色 层级 权限说明
user 1 普通用户，可管理自己的内容
moderator 2 版主，可编辑/删除任何帖子和评论
admin 3 管理员，可封禁/解封用户

错误处理

统一的错误响应格式。

错误响应格式

{
    "error": {
        "type": "error_type",
        "message": "错误描述信息"
    }
}

错误类型

类型 HTTP 状态码 说明
bad_request 400 请求格式错误
unauthorized 401 未认证或认证失败
forbidden 403 无权限执行此操作
not_found 404 资源不存在
conflict 409 资源冲突（如邮箱已存在）
validation_error 422 请求验证失败
rate_limit_exceeded 429 请求过于频繁
internal_server_error 500 服务器内部错误

错误响应示例

// 401 Unauthorized
{
    "error": {
        "type": "unauthorized",
        "message": "invalid or expired token"
    }
}

// 409 Conflict
{
    "error": {
        "type": "conflict",
        "message": "a user with that email already exists"
    }
}

// 429 Rate Limit
{
    "error": {
        "type": "rate_limit_exceeded",
        "message": "rate limit exceeded, retry after 5s"
    }
}

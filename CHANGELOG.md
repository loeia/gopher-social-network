# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-03

### Added

- User registration and authentication system with JWT tokens
- Email activation for new user accounts
- Password reset functionality via email
- Post creation, editing, and deletion
- Tag support for posts with filtering
- Full-text search functionality for posts
- Multi-level comment system with nested replies
- Like/unlike posts and comments
- User follow/unfollow system
- Activity feed showing posts from followed users
- Avatar upload with image cropping
- User profile management
- Rate limiting for API endpoints
- Redis caching for improved performance
- PostgreSQL 16 database with Goose migrations
- RESTful API design with proper status codes
- Docker Compose setup for development environment
- Comprehensive API documentation
- Admin features for user moderation (ban/unban)
- CORS configuration support
- Environment variable configuration system
- Vue 3.5 frontend with Composition API
- Element Plus UI components
- Pinia state management
- Vue Router 4 for frontend routing
- Vite 8 build tool for fast development
- TypeScript support for frontend
- CI/CD workflow for pull request checks
